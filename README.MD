# Nim Educational Bridge: Python's Syntax meets C's Power

This repository demonstrates why **Nim** is the ultimate bridge for computer science education. It compares Nim directly with Python (for high-level syntax and ease of use) and C (for low-level memory management and pointers).

## Projects Included:
1. **Guess the Number (`01_guessing_game/`)**: Compares Python and Nim syntax readability.
2. **Linked List Memory Management (`02_memory_management/`)**: Compares C's manual `malloc/free` memory control with Nim's zero-overhead automatic memory management (**ARC/ORC**).
